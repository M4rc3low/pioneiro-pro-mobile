# Suporte — Pioneiro Pro

## Problemas e sugestões

Para relatar um problema, sugerir uma melhoria ou acompanhar uma correção, use a área **Issues** deste repositório:

https://github.com/M4rc3low/pioneiro-pro-mobile/issues

Ao relatar um erro, informe quando possível:

- versão do Pioneiro Pro;
- Android ou iOS;
- modelo do aparelho;
- versão do sistema operacional;
- passos para reproduzir o problema;
- mensagem de erro ou captura de tela.

## Privacidade

Não publique em Issues nomes, telefones, endereços, backups ou outras informações pessoais armazenadas no aplicativo.

Para dúvidas sobre tratamento de dados, consulte [PRIVACY.md](PRIVACY.md).
