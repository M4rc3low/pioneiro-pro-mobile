# Política de Privacidade — Pioneiro Pro

**Última atualização:** 21 de setembro de 2026

O Pioneiro Pro foi desenvolvido com uma abordagem local-first. Na versão atual, os dados cadastrados pelo usuário são armazenados localmente no dispositivo.

## Dados armazenados

O aplicativo pode armazenar, conforme o uso:

- registros de atividades e tempo;
- nomes e informações de estudantes;
- agenda de estudos, revisitas e outros compromissos;
- metas e preferências do aplicativo;
- observações inseridas pelo próprio usuário.

## Armazenamento e transmissão

Na versão atual:

- os dados são mantidos no banco local do aplicativo;
- o aplicativo não envia automaticamente esses dados para um servidor próprio;
- não há venda de dados pessoais;
- não há publicidade no aplicativo;
- não há rastreamento para fins publicitários.

## Backup e exportação

O usuário pode exportar manualmente:

- backup dos dados em formato JSON;
- relatório de atividades em CSV;
- resumo em arquivo de texto.

Depois da exportação, o usuário é responsável por onde esses arquivos são armazenados ou compartilhados.

## Exclusão dos dados

Os registros podem ser excluídos dentro do aplicativo. A remoção dos dados do aplicativo/dispositivo também pode ser realizada por meio dos recursos do sistema operacional.

## Segurança

O usuário deve proteger o acesso ao próprio dispositivo e aos arquivos de backup exportados. Futuras versões que adicionem sincronização em nuvem, autenticação ou novos tipos de coleta deverão atualizar esta política.
